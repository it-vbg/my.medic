# my.medic

my.medic — проект семейного приложения для хранения медицинских документов, подготовки к приёмам и подбора блюд для общего стола. Родитель сможет вести свою карту и карту ребёнка из одного аккаунта. Общую книгу рецептов оба взрослых смогут редактировать со своих телефонов.

**Стадия проекта — проектирование.** Правила семейного доступа и совместного подбора блюд согласованы. Ниже описаны возможности будущей первой версии.

## Медицинская карта

- **Документы.** В выбранную карту можно будет загрузить PDF или фотографию анализа, выписки или заключения обследования. Извлечённые показатели будут связаны со страницей оригинала, чтобы можно было сверить и исправить распознанное значение.
- **Динамика.** Для одного показателя будут видны результаты по датам, единицы измерения и референсные диапазоны с каждого бланка. Для сравнения приложение будет учитывать лабораторию и метод исследования, если он указан.
- **Подготовка к приёму.** ИИ поможет найти рекомендации врача в документах и проверить, есть ли в карте результаты назначенного контроля. Если помощник предложит обсудить дополнительный анализ или консультацию специалиста, он укажет основание и источник. Перед визитом можно будет собрать краткую сводку, вопросы врачу и нужные документы.
- **Напоминания.** В мобильном приложении можно будет включить уведомления о записях к врачу и контрольных обследованиях. Из уведомления откроется соответствующая запись.

## Семейный доступ

У каждого взрослого будет свой аккаунт и личная медицинская карта. При загрузке документа, записи на приём или обращении к ИИ родитель выбирает, с чьей картой работает.

| Что доступно | Кто управляет |
| --- | --- |
| Медицинская карта взрослого | Карту открывает и ведёт её владелец. Приглашение в семейную кухню даёт доступ к общим рецептам. |
| Медицинская карта ребёнка | Родитель, создавший карту, выдаёт и отзывает доступ. Приглашённый второй родитель тоже может добавлять документы, вести записи к врачам и задавать вопросы по карте ребёнка. |
| Общие рецепты | Оба взрослых могут добавлять и редактировать блюда, менять число порций и заменять рецепт недели. Изменения синхронизируются между устройствами. |

## Один рецепт на семью

Раз в неделю семья будет получать один рецепт для тех, кто ест вместе. Можно выбрать обоих взрослых и при желании включить ребёнка. У каждого участника свои отметки «люблю», «не люблю» и «не ем». При подборе будут исключаться блюда с аллергенами, указанными участниками, и с продуктами, которые хотя бы один из них отметил как «не ем». Из остальных вариантов выбирается тот, который лучше всего учитывает вкусы всех участников.

Например, если оба любят овощи, а острое нравится одному, приложение сможет предложить запечённые овощи и подходящий по составу соус для отдельной подачи. Оба увидят одну карточку с ингредиентами, порциями и шагами приготовления.

## Планируемый стек

| Компонент | Технологии |
| --- | --- |
| Мобильное приложение для iOS и Android | React Native, Expo, TypeScript |
| Веб-кабинет для работы с картами и документами | Next.js, TypeScript |
| Аккаунты и права доступа | Supabase Auth, политики доступа PostgreSQL |
| Показатели, приёмы и рецепты | PostgreSQL |
| Оригиналы документов | Закрытое облачное хранилище Supabase Storage |
| Разбор документов и помощь ИИ | Серверная обработка PDF и сканов, распознавание текста и обращение к модели в рамках выбранной карты |
